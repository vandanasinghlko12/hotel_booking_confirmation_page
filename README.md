# Reflection Question

## Challenges encountered during project
One of the main challenges I encountered during this project was creating a layout that closely matched the reference design. Positioning the sidebar, receipt card,welcome card and information cards required several adjustments. I also faced debugging issues, such as CSS styles not applying because of mismatched class names, cards not overlapping correctly due to margin and positioning issues, and elements not aligning as expected. I had to check my HTML closing tags when the layout appeared broken. Understanding Bootstrap utility classes for spacing, alignment, and Flexbox also took practice.

## Your approach to solving these challenges.
To solve these challenges, I took a step-by-step approach by breaking the design into smaller sections and working on one section at a time. Whenever a style was not working, I checked my HTML structure, verified class names, and inspected my CSS properties. I used the browser's developer tools to identify styling issues and experimented with Flexbox, margins, padding, and positioning to correct the layout. I also referred to Bootstrap documentation and reviewed examples to understand utility classes better. Instead of rewriting everything, I made small changes, tested them in the browser, and adjusted the code until I achieved the desired result.

## Improvements you would make if given more time.
If I had more time, I would focus on making my website look closer to the original reference template. Although I completed the main sections, I feel that some details, such as the spacing between cards, the overlapping receipt and welcome cards, font sizes, colors, and alignment, still need improvement. I would spend more time comparing my design with the reference and making small adjustments to achieve a closer match. I would also make better use of Bootstrap grid, Flexbox, spacing, and utility classes instead of writing custom CSS for every element. This would help me create cleaner, more consistent, and responsive code.
